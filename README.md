🏘️ NeighborNode

A community-based service marketplace for people living in the same building or street.

NeighborNode allows residents to post services (e.g., laptop repair, yoga classes, lending tools) and enables others in the same locality to request or book those services.

🚀 Why NeighborNode?

In many communities, people have useful skills or resources — but there’s no simple platform to connect neighbors.

NeighborNode solves this by:

📢 Allowing residents to post services

🔍 Enabling users to search and filter services

📅 Providing a booking system

👤 Supporting secure user authentication

🏘️ Building stronger local communities

📦 Installation & Setup
1️⃣ Clone the Repository
git clone https://github.com/your-username/NeighborNode.git
cd NeighborNode

2️⃣ Setup Frontend
cd client
npm install
npm run dev


Frontend runs at:

http://localhost:5173

3️⃣ Setup Backend
cd server
npm install
npm run dev


Backend runs at:

http://localhost:5000
